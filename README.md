
# React + Angular — News Portal

Учебный проект по разработке веб-приложений на React и Angular.

Вариант 12: Новостной портал.

Репозиторий содержит два самостоятельных приложения,
связанных навигацией и передачей идентификаторов через URL.

## Структура проекта

- `react-news-portal` — новостной портал на React.
- `angular-news-list` — личный новостной раздел на Angular.

## React — новостной портал

Реализованы:

- лента новостей;
- категории новостей;
- поиск и фильтрация;
- просмотр полной новости;
- добавление новостей;
- редактирование и удаление;
- маршрутизация;
- загрузка дополнительных новостей из DummyJSON;
- сохранение пользовательских изменений в localStorage;
- переход к сохранению новости в Angular.

### Маршруты React

| Маршрут | Описание |
|---|---|
| `/` | Главная страница |
| `/news` | Лента новостей |
| `/news/:id` | Полная новость |
| `/news/:id/edit` | Редактирование |
| `/add-news` | Добавление новости |

## Angular — личный новостной раздел

Реализованы:

- сохранение новости по ID и названию;
- просмотр сохранённых новостей;
- удаление новости из сохранённых;
- отметка новости как прочитанной;
- фильтрация по статусу прочтения;
- история прочтения;
- сортировка истории по дате;
- маршрутизация, включая динамический маршрут;
- реактивная форма с валидацией;
- сервис для работы с данными;
- передача данных между компонентами;
- обработчики событий;
- директивы @if и @for;
- адаптивная CSS-вёрстка.

### Маршруты Angular

| Маршрут | Описание |
|---|---|
| `/` | Перенаправление на /saved |
| `/saved` | Сохранённые новости |
| `/saved/add` | Добавление новости |
| `/saved/:id` | Детали сохранённой новости |
| `/history` | История прочтения |

## Взаимодействие React и Angular

Приложения запускаются независимо друг от друга.

Из React можно перейти к сохранению конкретной новости
в Angular. Через URL передаются ID и заголовок новости.

Пример:

http://localhost:4200/saved/add?id=2&title=Example

Angular автоматически заполняет форму переданными данными.

Из Angular можно открыть полную новость в React по ID.

Пример:

http://localhost:5173/news/2

Если новость не найдена, отображается соответствующее
сообщение.

## Хранение данных

В React используются локальные демонстрационные новости
и данные API DummyJSON.

Изменения пользовательских новостей сохраняются
в localStorage React-приложения.

В Angular используются localStorage и SavedNewsService.

Хранятся:
- ID и заголовок сохранённой новости;
- дата сохранения;
- дата прочтения;
- история прочтения.

Изменения сохраняются после перезагрузки страницы.

React и Angular используют отдельные хранилища localStorage,
поскольку работают на разных портах.

Передача ID через URL не обеспечивает автоматическую
синхронизацию данных между приложениями.

Angular не проверяет существование введённого ID в React
при ручном добавлении новости.

## Запуск проекта

Необходимы Node.js и npm.

### React

```bash
cd react-news-portal
npm install
npm run dev
```

Адрес: http://localhost:5173

### Angular

```bash
cd angular-news-list
npm install
npm start
```

Адрес: http://localhost:4200

Для одновременной работы приложений необходимо
запустить их в двух отдельных терминалах.
