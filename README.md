# React + Angular app

Учебный проект, объединяющий два отдельных frontend-приложения:

- **React News Portal** — новостной портал на React;
- **Angular Game List** — каталог игр на Angular с загрузкой данных через REST API.

Приложения запускаются независимо друг от друга и связаны взаимными переходами.

## React News Portal

Новостной портал, разработанный на React и Vite.

Основные возможности:

- вывод списка новостей;
- просмотр отдельной новости;
- фильтрация и поиск;
- добавление новостей;
- редактирование новостей;
- удаление новостей;
- маршрутизация между страницами;
- сохранение пользовательских изменений в `localStorage`;
- переход в Angular-приложение.

---

## Angular Game List

Каталог игр, разработанный на Angular.

Основные возможности:

- получение списка игр через REST API;
- вывод игр в виде карточек;
- обработка состояния загрузки и ошибок;
- маршрутизация между страницами;
- получение параметра `id` из маршрута;
- загрузка и отображение информации об отдельной игре;
- переход обратно в React-приложение.

Для получения данных используется публичный API FreeToGame.

### Основные маршруты

```text
/            — главная страница
/games       — каталог игр
/games/:id   — информация об отдельной игре
/about       — информация о проекте
```

## Одновременный запуск

Для работы проекта необходимо открыть два терминала.

### Терминал 1 — React

```bash
cd react-news-portal
npm run dev
```

### Терминал 2 — Angular

```bash
cd angular-game-list
npm start
```

После запуска доступны оба приложения:

```text
React:   http://localhost:5173
Angular: http://localhost:4200
```
